# Start up Server
Navigate into server folder in terminal and run command:

`npm install`

After all dependencies have been installed, server can be started with command:

`npm run dev`

Check if server is running on localhost:5000/api

# Start up Client
Initial start up (first time):

Navigate into client folder in terminal and run command:

`npm install`

After all dependencies have been installed, client can be started with command:

`npm start`

Check if server is running on localhost:3000
